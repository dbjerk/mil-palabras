# Mil Palabras

Spanish vocabulary flashcards for the 1,000 most common Spanish words, starting with the top 100. Uses spaced repetition (SM-2): missed words come back within minutes, known words come back less and less often.

Works offline once loaded. Open the GitHub Pages site on your phone and choose **Add to Home Screen**.

Progress is stored in the browser on each device. Use **Options → Back up progress** to move it between devices.
